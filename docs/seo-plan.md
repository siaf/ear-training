# Fifths SEO Plan: 0 → Tonegym parity (~130k organic ETV) in 18 months

**Domain:** fifths.io · **App:** app.fifths.io · **Current organic footprint:** 0 ranked KWs (US/en).
**18-month traffic target:** ~130k monthly ETV (matches tonegym.co today).
**Method:** mirror tonegym's playbook — a small set of free in-browser tools + a programmatic theory glossary + a science-grounded blog — backed by a stronger interactive product.

## 10. Schema & on-page conventions

- Every tool page: `SoftwareApplication` + `HowTo` JSON-LD.
- Every glossary page: `DefinedTerm` + `FAQPage`.
- Every blog post: `Article` with author, datePublished, image.
- Every programmatic page: same template; only data swaps.
- Internal linking: every glossary page → relevant tool; every tool → 3+ programmatic pages + 1 blog article.
- Canonical: `https://fifths.io/<path>/`. Blog: `/blog/<slug>/`.
