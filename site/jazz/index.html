Frequently asked

I already finished Sonofield. Why switch?

Sonofield's great for the method. We add measurement — after every session you see which qualities or scale-degrees still fool you, not just "78%." And we're roughly a quarter the price.

What's in the advanced-modules pipeline?

Today: cadences, pop progressions, ii-V-I in major and minor, secondary dominants, modulation detection. Coming next (1–2 new Pro modules per month, prioritized from paying-user signals): altered dominants (♭9, ♯9, ♯11, ♭13), modal interchange, voicings (closed / drop-2 / quartal / upper-structure), and post-tonal interval-class work for the deepest tier.

Is there a free tier?

Yes. Full baseline curriculum + 7-day analytics. Pro unlocks advanced chord modules + unlimited history + mic input + auto-drill.

Do I need a MIDI keyboard?

No. Web + headphones + piano samples built in. Add a keyboard later if you want input on specific drills.
